## How to Set Up

1. Clone this repository:
   ```bash
   git clone https://github.com/KauaZs/profile-card
   ```

2. Navigate to the project directory:
   ```bash
   cd profile-card
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Create your .env file:
   ```env
   API_KEY=YourApiKey #  Visit https://github.com/KauaZs/profile-api
   API_URL=YourApiUrl # Example https://localhost:3001
   ```

## How to Run the Project

> **REQUIRED**: The API must be online: [Repository](https://github.com/KauaZs/profile-api)
```bash
npm run dev
```

The application will start at `http://localhost:5173` in your browser.
